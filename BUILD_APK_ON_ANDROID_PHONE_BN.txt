MY DAILY MANAGER — ANDROID APK PROJECT
========================================

এই ZIP-টি Android APK নয়; এটি APK build করার Android project।
কম্পিউটার ছাড়াই Android ফোন থেকে GitHub Actions ব্যবহার করে APK বানানো যাবে।

ফোন থেকে APK বানানোর ধাপ:
1) GitHub account-এ sign in করো।
2) github.com/new এ গিয়ে নতুন repository তৈরি করো। নাম: MyDailyManager-Android
3) Repository-তে এই ZIP-এর ভেতরের সব ফাইল ও folder upload করো (ZIP-টি extract করে upload করতে হবে)।
   গুরুত্বপূর্ণ: .github folder-টিও upload করবে। GitHub mobile site-এ hidden folder দেখা না গেলে
   browser-এর Desktop site চালু করো, অথবা GitHub app/একটি file manager দিয়ে upload করো।
4) Upload শেষ হলে repository → Actions tab খোলো।
5) "Build My Daily Manager APK" workflow নির্বাচন করে "Run workflow" চাপো।
   প্রথমবার push করলেও workflow নিজে শুরু হতে পারে।
6) Build সফল হলে workflow run-এর নিচে Artifacts অংশে
   "My-Daily-Manager-debug-apk" ডাউনলোড করো।
7) ZIP artifact extract করো। app-debug.apk ফাইলটি tap করে Install করো।
8) Android Settings চাইলে ওই browser/file manager-এর "Install unknown apps" অনুমতি দাও।
   APK install করার পর চাইলে সেই অনুমতি বন্ধ করে দিতে পারো।

এই project-এ:
- Web app assets APK-র ভেতরে bundle করা; app UI অফলাইনে চালানোর জন্য।
- Local data IndexedDB-তে থাকে; অ্যাপ uninstall বা app data clear করলে হারাতে পারো।
  নিয়মিত Backup থেকে JSON export করে আলাদা জায়গায় রাখবে।
- Native Android BiometricPrompt bridge আছে; Security page-এ register করে unlock করা যাবে।
- File chooser bridge আছে যাতে attachment picker Android-এ খুলতে পারে।
- PIN এবং JSON backup-কে পূর্ণাঙ্গ encryption ধরে নিও না।
- Calendar reminders এখনো অ্যাপ খোলা থাকাকালীন web notification checking-এর ওপর নির্ভরশীল;
  নির্ভরযোগ্য background alarm এই build-এ যোগ করা হয়নি।
- PDF report print window Android WebView-এ সীমিত হতে পারে; PDF feature-টি আলাদা করে যাচাই করা প্রয়োজন।

Troubleshooting:
- Actions tab না দেখালে repository-তে Actions enabled কিনা দেখো।
- Workflow না এলে .github/workflows/build-apk.yml path ঠিক আছে কিনা দেখো।
- Build failed হলে Actions run-এর red error message/screenshot পাঠাও।
